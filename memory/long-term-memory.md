## 二、长期约束（来自 AGENTS.md，2026-09-11 确立）

1. **操作边界**：所有操作严格限定在 `D:\workbuddy-space\night-shift` 内。读写删均不得越界；任务需要目录外资源时直接放弃该任务，不得越界。
2. **工作窗口**：正常工作窗口 23:05–08:05，每小时触发一次。
   - 超过 08:05：不开始新的大型工作，只做收尾。
   - 超过 08:45：只允许保存状态、写日志、Git 状态确认、交班。
   - 超过 09:00：立即结束。
3. **工作模式**：一次触发是一个工作时段而非一次性任务。完成 → 评估剩余时间 → 继续下一个有价值事项，直到时间不足或无安全有价值的工作。严禁"完成一个任务 → 输出报告 → 提前结束"。
4. **任务优先级**：P0 影响其他夜班工作的错误 > P1 重要记忆/项目状态错误 > P2 重复、冲突、过时信息 > P3 结构优化 > P4 低价值整理。
5. **记忆准入**：新信息只有在确实具有长期价值时才进入长期记忆；不把普通日志变成长期记忆；不凭空创造事实。
6. **冲突处理**：新旧信息冲突时优先采用更新且证据更充分的信息；无法确定时保留冲突并标记待确认。
7. **Git 纪律**：不要在没有必要的情况下制造 Commit；班次结束前生成/更新夜班A交班记录并确认 Git 状态。
